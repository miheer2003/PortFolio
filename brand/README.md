# Logo

The mark is a Geist "M" next to an Instrument Serif italic "j", and the dot of the j is the site's four-point star.

| File | Use it for |
|---|---|
| `logo-mark.svg`, `png/logo-mark.png` | Light backgrounds |
| `logo-mark-dark.svg`, `png/logo-mark-dark.png` | Dark backgrounds |
| `logo-lockup.svg`, `png/logo-lockup.png` | Mark with the name: résumé header, cover images |
| `logo-lockup-dark.svg`, `png/logo-lockup-dark.png` | The same on dark backgrounds |
| `logo-app-icon.svg`, `png/avatar.png` | Profile pictures (LinkedIn, GitHub). Safe for circle crops |
| `preview.png` | Everything at a glance |

Colours: espresso `#2A1A15`, burgundy `#5C1726`, latte `#FFF8E7`, cream `#E9D8BF`.

On the site, the navbar uses `src/components/Logo.tsx`. The tab and home-screen icons are `public/favicon.svg`, `public/favicon.ico`, `public/apple-touch-icon.png` and `public/icon-*.png`.

Both fonts are under the SIL Open Font License, so using their letter shapes in a logo is allowed.
