# Logo

The mark is a Geist "M" next to an Instrument Serif italic "j", and the dot of the j is the site's four-point star. The letters are outlined, so no fonts are needed. The same files are in the downloadable pack (`Mj-logo-pack.zip`).

| File | Use it for |
|---|---|
| `PNG/logo/Mj-logo-for-light-bg.png` | Light backgrounds (transparent, 2048 px tall) |
| `PNG/logo/Mj-logo-for-dark-bg.png` | Dark backgrounds and dark photos |
| `PNG/logo/Mj-logo-espresso.png`, `Mj-logo-latte.png` | One-colour use: print, stamps, watermarks |
| `PNG/logo-with-name/…-for-light-bg.png`, `…-for-dark-bg.png` | Mark with the name: résumé header, slides, LinkedIn banner (4000 px wide) |
| `PNG/profile-picture/Mj-profile-burgundy.png`, `Mj-profile-latte.png` | Profile pictures (1024 × 1024). Safe for circle crops |
| `PNG/app-icon/Mj-app-icon.png` | Rounded app icon with transparent corners |
| `SVG/` | The same logos as vector files |
| `preview.png` | Every file above, shown where it is meant to go |

Colours: espresso `#2A1A15`, burgundy `#5C1726`, latte `#FFF8E7`, cream `#E9D8BF`.

On the site, the navbar uses `src/components/Logo.tsx`. The tab and home-screen icons are `public/favicon.svg`, `public/favicon.ico`, `public/apple-touch-icon.png` and `public/icon-*.png`. The link preview image is `public/og-image.jpg`.

Both fonts are under the SIL Open Font License, so using their letter shapes in a logo is allowed.
