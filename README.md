## 🌟 Executive Overview

This repository houses the complete source code for **[miheerjangale.co.in](https://www.miheerjangale.co.in)**. Engineered to eliminate static resume monotony, this portfolio acts as a living showcase of high-concurrency systems, AI agent workflows, and tactile visual computing.

### 💎 Key Highlights

- 🖥️ **Interactive Embedded Terminal**: Built-in interactive CLI triggered via the `` ` `` key or floating `>_` widget with shell commands (`whoami`, `projects`, `skills`, `github`, `sudo`, `coffee`).
- ⌨️ **Interactive Canvas Mechanical Keycap Board**: Custom 2D/3D canvas keyboard where users can physically type or click keys to illuminate skills with wave ripple lighting.
- 🧠 **3D Neural Network (Three.js)**: Interactive synapsing neural mesh in the About section that rotates with scroll and fires energy pulses upon cursor click or tap.
- 🖼️ **Deformable WebGL Hero Portrait**: Mesh displacement reacting to user scroll momentum paired with a live-synced Pune timezone clock and date widget.
- 🎴 **Physics-Driven 3D Certificate Deck**: Endless stacked 3D card carousel with interactive drag gestures, swipe velocity, and card-flip inspection.
- 📈 **Dynamic Odometer Metric Counters**: Numeric roller animations tracking All India Rank 23 (CDAC PG-DAC), live GitHub stats, and internship throughput.
- ☕ **Native UPI / Buy Me a Coffee Gateway**: Dynamic modal generating instant UPI QR codes on desktop and native payment deep-links on mobile devices.
- ⚡ **60 FPS Hardware-Accelerated Motion**: Custom integration coupling Lenis smooth scrolling with GSAP `ScrollTrigger` directly on the requestAnimationFrame ticker.

## ⚡ Performance & Engineering Feats

- **Strict 60 FPS Animation Budget**: All visual motions are GPU-accelerated, modifying exclusively `transform` and `opacity` properties to prevent DOM reflows and paint thrashing.
- **Off-Screen WebGL Pausing**: Canvas and Three.js render loops pause automatically via `IntersectionObserver` when scrolled outside the active viewport, conserving GPU memory and battery.
- **Serverless GitHub Edge Caching**: The [`api/github.ts`](api/github.ts) edge handler pulls commit calendars and repositories, serving cached data to prevent client-side GitHub rate limits.
- **Lenis Smooth Momentum Sync**: GSAP `ScrollTrigger` and Lenis scrolling are unified via `gsap.ticker.add`, ensuring zero camera jitter across high-refresh monitors (120Hz/144Hz).
- **SEO & Search Crawler Readiness**: Initial HTML contains structured Schema.org JSON-LD profiles (`Person`, `ProfilePage`), semantic meta tags, and an [`llms.txt`](public/llms.txt) manifest for AI search agents.

## 💻 Local Development

Clone and spin up the project locally in under two minutes:

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **pnpm** / **yarn**

### 2. Clone the Repository
```bash
git clone https://github.com/miheer2003/PortFolio.git
cd PortFolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Development Server
```bash
npm run dev
```
Navigate to `http://localhost:5173` to explore the site with live hot module replacement.

### 5. Build for Production
```bash
npm run build
```
Generates a minified, tree-shaken, and production-optimized bundle inside the `dist/` directory.
